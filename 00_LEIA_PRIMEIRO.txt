❌ "Network Error ao fazer login"
✅ Solução: Espere 30 segundos após iniciar
   docker logs escambo-web | grep "API URL"
   Deve mostrar: 🐳 Rodando em Docker - API URL: http://backend:3000

❌ "Containers não iniciam"
✅ Solução: Limpar e reconstruir
   docker compose -p escambo down -v
   docker compose -p escambo up -d --build

❌ "Porta 5174 já em uso"
✅ Solução: Parar containers
   docker compose -p escambo down
   lsof -i :5174  (encontrar processo)

❌ "MySQL não conecta"
✅ Solução: Esperar mais tempo
   sleep 30
   docker logs escambo-db

Iniciar:
  docker compose -p escambo up -d

Ver logs:
  docker logs -f escambo-web      # Frontend
  docker logs -f escambo-api      # Backend
  docker logs -f escambo-db       # MySQL

Parar:
  docker compose -p escambo down

Limpar (reseta database):
  docker compose -p escambo down -v

Rebuild após mudanças:
  docker compose -p escambo down && docker compose -p escambo up -d --build

Acessar container:
  docker exec -it escambo-web sh

Testar API:
  curl http://localhost:3000/api/health
