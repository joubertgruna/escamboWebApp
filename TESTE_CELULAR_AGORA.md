## 🐛 SE ENCONTRAR ERRO

### Network Error (não carrega dados)
```
❌ Problema: Backend fora
✅ Solução: Verificar terminal do Mac
   Backend deve estar rodando
```

### Layout quebrado em celular
```
❌ Problema: Componente não responsivo
✅ Solução: Anotar página + screenshot
   Reportar depois
```

### Botão não responde
```
❌ Problema: Interatividade quebrada
✅ Solução: Verificar console do navegador
   (Developer Tools → Console)
```
