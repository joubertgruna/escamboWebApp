## 🔀 Fluxo de Usuário

### Novo Usuário (Não logado)
```
Acessa http://localhost:5174/
        ↓
   Vê Landing Page
        ↓
┌─ Clica em [Começar Agora]
├─ Clica em [Já tenho conta]  ← Login
├─ Clica em [Entrar]           ← Login
├─ Clica em [Cadastrar]        ← Register
├─ Lê sobre Propósito
├─ Lê sobre Ferramentas
├─ Lê sobre Soluções
└─ Clica em [CTA Final]
        ↓
   Vai para /register
        ↓
   Preenche formulário
        ↓
   Cria conta
        ↓
   Acessa /feed ✓
```

### Usuário Existente (Logado)
```
Acessa http://localhost:5174/
        ↓
   Detecta isAuthenticated
        ↓
   Redireciona para /feed ✓
```

├─ Buttons: +400ms
├─ Icons: +600ms
└─ Scroll Indicator: infinite

Scroll Animations:
├─ Header: 600ms (on scroll)
├─ Card 1: 600ms + 0ms
├─ Card 2: 600ms + 200ms
├─ Card 3: 600ms + 400ms

Logo Animation:
└─ Rotate: 20s infinite (linear)

└─ Scale: 105% (150ms)

## 📏 Measurement Cheat Sheet

```
SPACING
├─ 4px = 1  (very small gaps)
├─ 8px = 2  (small gaps)
├─ 16px = 4 (padding standard mobile)
├─ 24px = 6 (padding standard desktop)
├─ 32px = 8 (gap between cards)
└─ 80px = 20 (section padding vertical)

TYPOGRAPHY
├─ 14px = text-sm
├─ 16px = text-base
├─ 18px = text-lg
├─ 20px = text-xl
├─ 24px = text-2xl
├─ 32px = text-4xl
├─ 42px = text-5xl
├─ 56px = text-6xl
└─ 72px = text-7xl

BREAKPOINTS
├─ 320px = min mobile
├─ 390px = iPhone 12
├─ 640px = sm
├─ 768px = md
└─ 1024px = lg

RADIUS
├─ 8px = rounded-lg
├─ 12px = rounded-xl
├─ 16px = rounded-2xl
└─ 9999px = rounded-full

SHADOWS
├─ sm = shadow-sm
├─ md = shadow-md (default)
├─ lg = shadow-lg (on hover)
└─ xl = shadow-xl
```
